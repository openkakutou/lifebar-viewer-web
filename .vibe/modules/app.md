# Module: app
**Role:** Application entry point — mounts the root frame into the DOM, built on the shared `web-ui-kit` design system, with a fallback error state if the design tokens stylesheet fails to load. The frame's toolbar hosts the app title plus a `<wuik-locale-switcher>` (backlog item 008); its `<main>` region hosts the lifebar folder input (which also resolves the lifebar's sprite sheet), the simulation controls, and the elements panel. Owns the elements panel's selection object and the simulation controls' values object, re-rendering the panel (with both) after either the lifebar document or the sprite sheet store changes, and re-rendering both the controls and the panel whenever a simulated value changes. A freshly-loaded lifebar reseeds every simulatable slot at its own default value. The real bootstrap (`mount()`) awaits `initAppI18n()` before the first render, so the app never flashes English before a persisted locale resolves; `renderApp` itself stays synchronous and never calls it. A single `onLocaleChange` subscription (torn down and re-made at the top of every `renderApp` call, never accumulating) re-invokes the same refresh closures on a language switch, so the current selection and simulated values survive it untouched.
**Files:** `src/main.ts`, `src/style.css`, `src/version.ts`
**Exports:** `appVersion: string`, `renderApp(root, version, options?)`, `designTokensLoaded(target?): boolean`, `RenderAppOptions`
**Depends on:** `@openkakutou/web-ui-kit` (external), `modules/input.md`, `modules/document.md`, `modules/elements.md`, `modules/simulation.md`, `modules/i18n.md`
