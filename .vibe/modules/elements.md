# Module: elements
**Role:** The elements panel + preview renderer (backlog item 004): lists every recognized element of a loaded lifebar and draws a live composite of them on a fixed `640×480` canvas, using sprites resolved from the loaded `.sff` sheet. Selecting an element highlights its region via a DOM overlay; an unresolved sprite reference, an element with no sprite layers, and "no sheet loaded yet" are three visually distinct states, never one generic placeholder. See `.vibe/decisions/004-element-layout-convention-and-placeholder-states.md`.
**Files:** `src/elements/element-layout.ts`, `src/elements/elements-panel.ts`
**Exports:** `computeElementLayout(section)`, `computeElementBox(layout, spriteGroups)`, `resolveLayer(layer, spriteGroups)`, `layerBox(...)`, `layerPosition(...)`, `parsePoint(value)`, `clampBoxToCanvas(box)`, `PREVIEW_CANVAS_WIDTH`, `PREVIEW_CANVAS_HEIGHT`, `PLACEHOLDER_SIZE`, `renderElementsPanel(root, document, spriteGroups, sffBytes, options?)`, `defaultDrawSprite(...)`, `ElementsPanelOptions`, `ElementSelection`
**Depends on:** `modules/lifebar.md` (`LifebarDocument`/`LifebarSection` types), `modules/wasm.md` (`SpriteGroup`/`Sprite` types, `resolveSpritePixels`)
