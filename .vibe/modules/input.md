# Module: input
**Role:** Folder-based lifebar input — gathers files from a directory picker or a dropped folder, detects which is a plausible lifebar file, resolves which one to load (auto if there's exactly one, asks the user if several), reads and parses it, and renders the picker/drop-zone/selection-prompt/status UI. Once the lifebar loads, also resolves its sprite sheet from that same gathered file list — auto-picking among several `.sff` candidates using the lifebar's own declared `[Files]`/`sff` file name when one matches — see `.vibe/decisions/003-sprite-sheet-resolved-from-the-same-folder-no-separate-picker.md`.
**Files:** `src/input/folder-entries.ts`, `src/input/candidate-files.ts`, `src/input/lifebar-folder-input.ts`, `src/input/lifebar-folder-input-view.ts`, `src/input/sprite-sheet-folder-input.ts`
**Exports:** `GatheredFile`, `filesFromWebkitDirectoryFiles(files)`, `filesFromDataTransferItems(items)`, `collectFilesFromEntry(entry)`, `EntryLike`/`FileEntryLike`/`DirectoryEntryLike`/`DirectoryReaderLike`/`DataTransferItemLike`, `isCandidateLifebarFile(gathered)`, `findCandidateLifebarFiles(files)`, `isCandidateSpriteSheetFile(gathered)`, `findCandidateSpriteSheetFiles(files)`, `resolveCandidates(files)`, `CandidateResolution`, `loadLifebarFromFolderFiles(files, options?)`, `loadLifebarFromChosenEntry(entry, options?)`, `LifebarFolderInputResult`, `LifebarFolderInputOptions`, `readFileAsText(file)`, `renderLifebarFolderInput(root, options)`, `LifebarFolderInputViewOptions`, `loadSpriteSheetFromFolderFiles(files, options?)`, `SpriteSheetFolderResult`, `SpriteSheetFolderInputOptions`, `readFileAsBytes(file)`
**Depends on:** `@openkakutou/web-ui-kit` (external, `<wuik-button>` for the folder-input view's reset/confirm buttons — org-wide UX audit, backlog item 012), `modules/lifebar.md`, `modules/wasm.md`, `modules/i18n.md` (the folder-input view translates its own labels/status/error text and re-formats the currently-shown status from a stored status descriptor on a locale change, rather than a pre-formatted string)
